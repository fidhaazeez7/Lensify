# 🚀 Lensify

> AI-Powered Source Code Analysis Platform

Lensify is an AI-powered web application that analyses software projects and provides insights into architecture, security, performance, documentation quality, code health, and potential bugs. It also generates AI-powered recommendations and downloadable PDF reports.

---

## ✨ Features

- 📂 Upload ZIP projects
- 🏗️ Architecture analysis
- 🔍 Technology detection
- 🛡️ Security vulnerability detection
- 🐞 Bug detection
- ⚡ Performance analysis
- 📖 Documentation analysis
- ❤️ Project health score
- 🤖 AI project review
- 💬 AI Assistant for project questions
- 📄 Downloadable PDF reports

## 🚀 Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
